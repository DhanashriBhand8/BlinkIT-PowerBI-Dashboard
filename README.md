# BlinkIT Power BI Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze BlinkIT e-commerce sales and business performance.

The dashboard provides insights into sales, products, stock levels, delivery performance, and customer buying patterns.

## 🎯 Objectives

- Analyze total sales
- Identify top-selling products
- Analyze product categories
- Monitor stock levels
- Analyze average delivery time
- Identify fast-selling products
- Analyze sales by location
- Track overall business performance

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📌 Key KPIs

- Total Sales
- Total Orders
- Average Sales
- Average Delivery Time
- Top Selling Products
- Stock Availability

## 📈 Dashboard Features

- Interactive charts
- KPI cards
- Slicers and filters
- Sales analysis
- Product analysis
- Location-wise analysis
- Stock analysis
- Delivery performance analysis

## 📂 Project Files

- `BlinkIT_Dashboard.pbix` - Power BI dashboard
